Demonstration Risk-Scoring Algorithm Formula & Weights

The demonstration risk engine evaluates hydrological input vectors through a transparent normalized multi-criteria weighting equation:

Risk Score = (0.35 × IWater) + (0.30 × IRain) + (0.15 × IAntecedent) + (0.12 × ISoil) + (0.08 × IAtmos) × DFactor
35% River Gauge Height (IWater): Normalized against critical bank-full stage (7.5 meters).
30% 24-Hour Rainfall (IRain): Exponential curve exceeding flash-flood threshold of 120 mm.
15% 3-Day Antecedent Rain (IAntecedent): Captures cumulative watershed basin moisture storage.
12% Soil Saturation (ISoil): Pore saturation limits infiltration, triggering overland sheet runoff.
8% Atmospheric Index (IAtmos): Compound function of relative humidity and vapor deficit.
0 - 34: Low 35 - 59: Medium 60 - 79: High 80 - 100: Critical

Flood Safety Protocols & Standard Operating Procedures

Guidelines for communities and emergency responders before, during, and after flood events.

1. Pre-Flood Preparation
  • Prepare emergency go-bag: potable water (3 days), non-perishables, flashlight, battery radio.
  • Elevate critical electrical appliances and shut off main circuit breakers.
  • Verify community evacuation route to designated high ground or cyclone/flood shelters.
  • Secure hazardous chemicals, fuel tanks, and outdoor furniture.
2. During Active Flood Wave
  • "Turn Around, Don't Drown": Never walk or drive through moving water. 15cm sweeps people; 30cm moves cars.
  • Move immediately to upper stories or roof if trapped in building. Avoid attic without roof exit.
  • Keep emergency radio tuned to AquaGuard hydro-telemetry bulletins.
  • Signal distress using bright cloth, flashlight, or emergency whistle.
3. Post-Flood Recovery
  • Return home only after civil authorities announce safe clearance.
  • Inspect structural integrity before entering; beware of collapsed ceilings or sinkholes.
  • Discard all food and tap water that contacted flood runoff. Disinfect contaminated surfaces.
  • Document all damages with photographs for municipal insurance claims.

About AquaGuard & Future ML Backend Architecture

AquaGuard HydroPredict Platform

AquaGuard is an open-architecture, responsive Flood Prediction and Early Warning decision-support system. Designed with modern front-end web standards (HTML5, CSS3, and Vanilla JavaScript), it demonstrates how hydrological sensor telemetry, rainfall intensity, antecedent soil moisture, and atmospheric indicators can be combined into clear operational risk intelligence.

Zero-Dependency Core: Built without heavy frameworks (No React, Angular, or Vue). Lightweight, fast, and accessible on any device.
Transparent Algorithmic Scoring: Every risk output is backed by an inspectable mathematical weighting formula, making it ideal for educational research and calibration.
Ready for Python ML Backend: Designed from the ground up to connect seamlessly with real Python Machine Learning models (Scikit-Learn, XGBoost, or PyTorch LSTM).

How to connect AquaGuard to a real FastAPI / Flask / Scikit-Learn microservice.

API Blueprint v1.0

In script.js, the API layer is organized via the FloodPredictionService module. By toggling CONFIG.USE_MOCK_API = false and providing your backend URL, the system immediately switches from the in-browser demonstration algorithm to real model inference: 

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field
import joblib
import numpy as np

app = FastAPI(title="AquaGuard ML Flood Prediction API", version="1.0")

# Load pre-trained Random Forest or XGBoost model
model = joblib.load("flood_risk_xgboost_model.pkl")

class TelemetryPayload(BaseModel):
    station_id: str
    rainfall_24h_mm: float = Field(..., ge=0, le=600)
    river_water_level_m: float = Field(..., ge=0, le=25)
    previous_rainfall_72h_mm: float = Field(..., ge=0, le=800)
    soil_saturation_pct: float = Field(..., ge=0, le=100)
    temperature_c: float
    humidity_pct: float
    drainage_factor: float = 1.0

@app.post("/api/v1/predict")
def predict_flood_risk(data: TelemetryPayload):
    # Feature engineering vector
    features = np.array([[
        data.rainfall_24h_mm,
        data.river_water_level_m,
        data.previous_rainfall_72h_mm,
        data.soil_saturation_pct,
        data.temperature_c,
        data.humidity_pct,
        data.drainage_factor
    ]])
    
    risk_score = float(model.predict(features)[0])
    risk_score = max(0.0, min(100.0, risk_score))
    
    if risk_score >= 80:
        level, lead_time = "Critical", "< 6 Hours"
    elif risk_score >= 60:
        level, lead_time = "High", "6 - 18 Hours"
    elif risk_score >= 35:
        level, lead_time = "Medium", "18 - 36 Hours"
    else:
        level, lead_time = "Low", "> 48 Hours"

    return {
        "risk_score": round(risk_score, 1),
        "risk_level": level,
        "lead_time": lead_time,
        "confidence": 0.942,
        "status": "success"
    }
// HTTP POST /api/v1/predict
// Request Body:
{
  "station_id": "Station Alpha (North River Valley)",
  "rainfall_24h_mm": 125.4,
  "river_water_level_m": 6.85,
  "previous_rainfall_72h_mm": 140.2,
  "soil_saturation_pct": 88,
  "temperature_c": 23.5,
  "humidity_pct": 94,
  "drainage_factor": 1.15
}

// Response (200 OK):
{
  "risk_score": 78.4,
  "risk_level": "High",
  "lead_time": "6 - 12 Hours",
  "runoff_ratio": 0.74,
  "confidence": 0.938,
  "contributions": {
    "water_level": 31.9,
    "rainfall": 24.1,
    "antecedent": 11.2,
    "soil_saturation": 11.2
  }
}
// Located in script.js - Simple Toggle
const CONFIG = {
  USE_MOCK_API: true, // Set to false for live Python backend
  API_BASE_URL: 'http://localhost:8000/api/v1',
};

async function predictRiskAPI(payload) {
  if (CONFIG.USE_MOCK_API) {
    return computeDemonstrationRisk(payload);
  }
  
  const response = await fetch(`\${CONFIG.API_BASE_URL}/predict`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(payload)
  });
  return await response.json();
}
